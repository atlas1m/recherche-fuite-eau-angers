Static local SEO MVP.

## Local check

```bash
npm run check
python3 -m http.server 8765
```

## Deployment

Recommended fast stack: GitHub repo + Vercel static deploy.

Before production custom domain:
- replace `REPLACE_WITH_DOMAIN` in `robots.txt` and `sitemap.xml`;
- complete legal identity in mentions/privacy;
- connect Google Search Console after domain validation.
